# Zumba Bot

Telegram-бот для записи и продажи абонементов на занятия зумбой: информация о занятиях, пробные и обычные абонементы, рассылки от админа, тикеты поддержки через инлайн-интерфейс.

## Стек

`pyTelegramBotAPI` (telebot), профили пользователей — в файлах (JSON), очередь тикетов поддержки — в памяти процесса.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить токен и ID админов
python zumba.py
```
